## Установка

<!-- rimmods:readme installation begin -->
1. Установите [Harmony](https://steamcommunity.com/sharedfiles/filedetails/?id=2009463077) и [Keyz' Allow Utilities](https://steamcommunity.com/sharedfiles/filedetails/?id=3524716849).
2. Включите моды в порядке: Harmony → оригинальный мод → этот перевод.
3. Выберите русский язык в настройках RimWorld.
<!-- rimmods:readme installation end -->

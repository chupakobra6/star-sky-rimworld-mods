# Visible Raid Points — Russian translation [Star Sky Mods]

Russian localization for [Visible Raid Points](https://steamcommunity.com/sharedfiles/filedetails/?id=2562730174), targeting RimWorld 1.6. Install the original mod separately.

## Coverage

- Threat-point labels in letters and the detailed points breakdown.
- Event names and explanations of multipliers, limits and intermediate totals.
- Display settings and event selection.

## Installation

1. Install [Harmony](https://steamcommunity.com/sharedfiles/filedetails/?id=2009463077) and [Visible Raid Points](https://steamcommunity.com/sharedfiles/filedetails/?id=2562730174).
2. Enable this translation after the original mod; Harmony must load before both.
3. Select Russian in RimWorld’s language settings.

Use one Russian translation of this mod to avoid competing text overrides.

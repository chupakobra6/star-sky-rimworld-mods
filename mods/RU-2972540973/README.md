Самый полный русский перевод [Enhanced Carrying Capacity](https://steamcommunity.com/sharedfiles/filedetails/?id=2972540973) для RimWorld 1.6. Оригинальный мод устанавливается отдельно.

Enhanced Carrying Capacity позволяет настроить переносимый вес с помощью множителя и прибавки. С Combat Extended можно отдельно изменить допустимый объём снаряжения.

## Установка и использование

<!-- rimmods:readme installation begin -->
1. Установите [Enhanced Carrying Capacity](https://steamcommunity.com/sharedfiles/filedetails/?id=2972540973).
2. Включите моды в порядке: оригинальный мод → этот перевод.
3. Выберите русский язык в настройках RimWorld.
<!-- rimmods:readme installation end -->

Откройте настройки Enhanced Carrying Capacity и задайте множители и прибавки. Настройки объёма используются с Combat Extended.

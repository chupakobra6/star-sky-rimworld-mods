# Источники и уведомления

Русский перевод [Mythic Ages: Megafauna Bestiary](https://steamcommunity.com/sharedfiles/filedetails/?id=3537788184). Автор оригинального мода: Veterano.

## Исходные материалы

Источники переводимых текстов — установленный оригинальный мод версии 1.1.7 для RimWorld 1.6: определения в `1.6/Defs/`, английские языковые файлы и сообщения из игровой сборки. В проверенном пакете есть английская и бразильская португальская локализации; русская локализация в нём отсутствует.

Файл `LICENSE` оригинального пакета содержит Creative Commons Attribution 4.0 International. Полный текст сохранён в [Licenses/UPSTREAM-CC-BY-4.0.txt](Licenses/UPSTREAM-CC-BY-4.0.txt).

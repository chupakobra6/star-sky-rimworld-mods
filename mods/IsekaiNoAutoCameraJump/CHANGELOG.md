# Changelog

## 1.1.2 — 2026-09-17

- Changed the package ID from `chupakobra6.isekai.noautohuntcamerajump` to `starsky.rimworld.isekai.noautohuntcamerajump`. Re-enable the mod if the old ID leaves it inactive after updating. Camera behaviour is unchanged.

## 2026-09-17 — Workshop page

- Refreshed the cover using the original ISEKAI artwork with a Star Sky Mods frame.
- Expanded the English/Russian feature and installation details; added illustrated sections and links to mods, updates and support.
- Unified author credit as chupakobra6 | Star Sky Mods. That page-only update did not change the downloaded mod files.

## 1.1.1 — 2026-08-24

- Moved the package ID and Harmony ID into the stable chupakobra6 namespace used at that release.
- Kept the existing Steam Workshop item, 3789336886.
- Added an explicit mod version to About.xml.

## 1.1.0 — 2026-08-24

- Added RimWorld’s standard mod-settings menu.
- Added separate switches for ordinary ISEKAI hunts and Creatures hunt packs.
- Kept the existing behaviour with the recommended defaults.
- Added English and Russian settings text.

## 1.0.0 — 2026-08-24

- First public release for RimWorld 1.6.
- Stopped the forced camera jump when a local ISEKAI hunt spawns its target.
- Kept letters, messages, clickable targets and all other camera jumps.
- Added support for ISEKAI CREATURES ADD-ON hunts.

# Источники и уведомления

Этот отдельный мод исправляет работу [Character Editor](https://steamcommunity.com/sharedfiles/filedetails/?id=1874644848) автора void. Оригинальный мод необходим для работы исправлений и распространяется отдельно. Исходные файлы Character Editor в этот пакет не включены.

`Source/Fixes.cs` и собранная из него DLL — собственный код chupakobra6 | Star Sky Mods, 2026, под [MIT](LICENSE). Код вызывает методы установленного Character Editor через Harmony. Условия MIT относятся к собственному коду исправлений, а не к исходному моду.

Сопроводительные тексты и интерфейсное имя этого пакета созданы для Character Editor — Fixes.

Обложка `About/Preview.png` создана для этого пакета из собственных векторных элементов; её редактируемый источник — `assets/sources/character-editor-fixes-cover.svg` в проекте Star Sky Mods. Автор обложки: chupakobra6 | Star Sky Mods, 2026. Иллюстрации и файлы Character Editor в обложке не использованы. Лицензия MIT в этом пакете относится к собственному коду исправлений; она не объявляет чужие материалы частью этого кода.

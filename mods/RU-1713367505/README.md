# RimSaves — Russian translation [Star Sky Mods]

Russian localization for [RimSaves](https://steamcommunity.com/sharedfiles/filedetails/?id=1713367505), targeting RimWorld 1.6. Install the original mod separately.

## Coverage

- Save and folder management, including move, rename and delete actions.
- Quicksave, autosave and incident-save settings.
- Save previews, sorting, tooltips and notifications.

## Installation

1. Install [Harmony](https://steamcommunity.com/sharedfiles/filedetails/?id=2009463077) and [RimSaves](https://steamcommunity.com/sharedfiles/filedetails/?id=1713367505).
2. Enable this translation after the original mod; Harmony must load before both.
3. Select Russian in RimWorld’s language settings.

Use one Russian translation of this mod to avoid competing text overrides.

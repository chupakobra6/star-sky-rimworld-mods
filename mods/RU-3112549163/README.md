## Что переведено

<!-- rimmods:readme translation begin -->
Я перевёл тексты библиотеки, уделяя внимание описаниям генов, ресурсов и способностей. Термины согласованы с русской локализацией RimWorld. Выберите русский язык в настройках RimWorld

## Установка

<!-- rimmods:readme installation begin -->
1. Установите [Harmony](https://steamcommunity.com/sharedfiles/filedetails/?id=2009463077) и [EBSG Framework](https://steamcommunity.com/sharedfiles/filedetails/?id=3112549163).
2. Включите моды в порядке: Harmony → оригинальный мод → этот перевод.
3. Выберите русский язык в настройках RimWorld.
<!-- rimmods:readme installation end -->

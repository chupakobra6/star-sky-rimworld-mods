# Collection Presets [Star Sky Mods]

[![Collection Presets](https://raw.githubusercontent.com/chupakobra6/star-sky-assets/main/assets/collection-presets.png)](https://steamcommunity.com/sharedfiles/filedetails/?id=3804220746)

[Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3804220746) · [All categories](../../README.md) · [Sources & notices](NOTICES.md)

<!-- rimmods:readme intro begin -->
Apply recommended mod settings from one in-game window. Choose individual presets or apply all available presets; enabling Collection Presets does not change your settings automatically.
<!-- rimmods:readme intro end -->

## Features

<!-- rimmods:readme features begin -->
- Find presets supplied by your active mods in one place.
- Includes a ×2 mass and bulk preset for Enhanced Carrying Capacity; bulk applies with Combat Extended.
- Change only the fields listed in each preset, preserving unrelated settings.
- Undo the last application, with protection against overwriting later manual changes.
<!-- rimmods:readme features end -->

## How to use

<!-- rimmods:readme how-to-use begin -->
From the main menu, open Mod Settings and select Collection Presets. Tick the presets you want, then click “Apply selected presets”. Use “Select all available” to choose the available set, or “Undo last application” to revert the previous application.
<!-- rimmods:readme how-to-use end -->

## Compatibility

<!-- rimmods:readme compatibility begin -->
RimWorld 1.6. The target mod must be active for its preset to be available. Apply and undo presets from the main menu, with no colony loaded. Restart the game after applying settings if a target mod caches them.
<!-- rimmods:readme compatibility end -->

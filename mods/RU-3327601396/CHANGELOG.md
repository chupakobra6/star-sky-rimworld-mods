# История изменений

## 1.0.1

- Из исправлений оставлено только условное удаление западного дубликата стойки с мечами при наличии южного определения с тем же именем
- Удалены остальные патчи совместимости и код исправления загрузки Ideology: эти ошибки исправил автор оригинального мода
- Для трёх строк культуры и категории стиля условие применения перевода изменено с Royalty на Ideology в соответствии с обновлённым оригиналом

## 1.0.0

Первый выпуск русского перевода Medieval Overhaul: House Van Illa для RimWorld 1.6

- Переведены тексты Дома Ван Илла, задания, письма, награды и списки имён; добавлены русские формы слов
- Устранено повторное определение стойки с мечами
- Рецепт инеевой накидки привязан к ручному швейному столу
- Исправлен путь к текстуре парирующего кинжала для второй руки
- Значение дикости LunarCygnus `0.25` перенесено в используемую игрой характеристику
- Радиус уклонения приведён к корректному целому значению `1`, которое игра фактически использовала и раньше
- Из четырёх рецептов еды удалена ссылка на отсутствующий стол; остальные места приготовления сохранены
- Для исследования одежды исправлено необходимое предшествующее исследование: `DankPyon_Tailoring` заменено на `ComplexClothing`
- Удалены лишние пробелы в двух ссылках на предписания идеологии
- В списке запрещённых идеологических мемов ссылка `Cannibalism` заменена на существующую `Cannibal`
- Удалена ссылка способности на отсутствующий звук `PsychicCalmCast`
- Загрузка содержимого для Ideology проверяет наличие Ideology вместо Royalty

Самый полный русский перевод [Medieval Overhaul: House Ignivar](https://steamcommunity.com/sharedfiles/filedetails/?id=3712538846) для RimWorld 1.6. Оригинальный мод устанавливается отдельно.

House Ignivar добавляет в Medieval Overhaul средневековый дом, чьи воины и снаряжение закалены огнём и пеплом. У фракции есть собственные оружие, доспехи, еда, исследования и стартовые сценарии.
<!-- rimmods:readme intro end -->

## Что переведено

<!-- rimmods:readme features begin -->
Переведены все тексты мода с учётом правильных окончаний и согласования слов.

- Названия и описания фракций, воинов и стартовых сценариев.
- Оружие, доспехи, растения, блюда, напитки, рецепты и исследования.
- Состояния здоровья, мысли и тексты содержимого для Odyssey.
<!-- rimmods:readme features end -->

## Установка и использование

<!-- rimmods:readme installation begin -->
1. Установите [Medieval Overhaul](https://steamcommunity.com/sharedfiles/filedetails/?id=3219596926) и [Medieval Overhaul: House Ignivar](https://steamcommunity.com/sharedfiles/filedetails/?id=3712538846).
2. Включите моды в порядке: Medieval Overhaul → оригинальный мод → этот перевод.
3. Выберите русский язык в настройках RimWorld.
<!-- rimmods:readme installation end -->

Дом Игнивар доступен среди фракций при создании мира. Для игры за него выберите один из добавленных модом стартовых сценариев.

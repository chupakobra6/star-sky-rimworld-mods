# QualityBuilder Unofficial 1.6 — Russian translation [Star Sky Mods]

Russian localization for [QualityBuilder Unofficial 1.6](https://steamcommunity.com/sharedfiles/filedetails/?id=3512466087), targeting RimWorld 1.6. Install the original mod separately.

## Coverage

- Minimum-quality commands and quality-control toggles.
- Builder skill, per-map settings and mechanoid participation.
- Rebuild limits and the notification shown when the quality target is not reached.

## Installation

1. Install [Harmony](https://steamcommunity.com/sharedfiles/filedetails/?id=2009463077) and [QualityBuilder Unofficial 1.6](https://steamcommunity.com/sharedfiles/filedetails/?id=3512466087).
2. Enable this translation after the original mod; Harmony must load before both.
3. Select Russian in RimWorld’s language settings.

Use one Russian translation of this mod to avoid competing text overrides.

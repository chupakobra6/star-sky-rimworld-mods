# SimpleCameraSetting — Russian translation [Star Sky Mods]

Russian localization for [SimpleCameraSetting](https://steamcommunity.com/sharedfiles/filedetails/?id=3232415388), targeting RimWorld 1.6. Install the original mod separately.

## Coverage

- Zoom limits and camera movement and zoom speed settings.
- Pawn following, smoothing and follow-status messages.
- Silhouette, selection-bracket and overlay settings, plus mouse-button and scroll labels.

## Installation

1. Install [Harmony](https://steamcommunity.com/sharedfiles/filedetails/?id=2009463077) and [SimpleCameraSetting](https://steamcommunity.com/sharedfiles/filedetails/?id=3232415388).
2. Enable this translation after the original mod; Harmony must load before both.
3. Select Russian in RimWorld’s language settings.

The original SimpleCameraSetting mod is incompatible with Camera+.

Use one Russian translation of this mod to avoid competing text overrides.

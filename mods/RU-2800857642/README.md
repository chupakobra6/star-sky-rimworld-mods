# Map Preview — русский перевод [Star Sky Mods]

[![Map Preview — русский перевод](https://raw.githubusercontent.com/chupakobra6/star-sky-assets/main/assets/map-preview-translation.png)](https://steamcommunity.com/sharedfiles/filedetails/?id=3807814502)

[Мастерская](https://steamcommunity.com/sharedfiles/filedetails/?id=3807814502) · [Все категории](../../README.md) · [Источники и уведомления](NOTICES.md)

Русский перевод Map Preview для RimWorld 1.6. Оригинальный мод устанавливается отдельно.

Map Preview показывает будущую карту местности при выборе клетки на карте мира. Можно оценить расположение воды, гор и открытого пространства до основания поселения.

## Что переведено

<!-- rimmods:readme features begin -->
Переведены названия, настройки и подсказки предпросмотра карты.

- Настройки окна предпросмотра и панели инструментов карты мира.
- Подписи кнопок предпросмотра и смены семени карты.
- Сообщения об ожидании и ошибках при создании предпросмотра.
<!-- rimmods:readme features end -->

## Установка

<!-- rimmods:readme installation begin -->
1. Установите [Harmony](https://steamcommunity.com/sharedfiles/filedetails/?id=2009463077) и [Map Preview](https://steamcommunity.com/sharedfiles/filedetails/?id=2800857642).
2. Включите моды в порядке: Harmony → оригинальный мод → этот перевод.
3. Выберите русский язык в настройках RimWorld.
<!-- rimmods:readme installation end -->

На карте мира выберите клетку, чтобы открыть предпросмотр. Размер окна меняется в настройках Map Preview; кнопка в правом нижнем углу карты мира включает и выключает предпросмотр.

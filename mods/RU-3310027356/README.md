## Что переведено

Я перевёл интерфейс управления и подсказки, сохраняя различия между условиями заданий и согласованные названия ресурсов и работ. Выберите русский язык в настройках RimWorld

## Установка

<!-- rimmods:readme installation begin -->
1. Установите [Harmony](https://steamcommunity.com/sharedfiles/filedetails/?id=2009463077), [ilyvion's Laboratory](https://steamcommunity.com/sharedfiles/filedetails/?id=3296362231) и [Colony Manager Redux](https://steamcommunity.com/sharedfiles/filedetails/?id=3310027356).
2. Включите моды в порядке: Harmony → ilyvion's Laboratory → оригинальный мод → этот перевод.
3. Выберите русский язык в настройках RimWorld.
<!-- rimmods:readme installation end -->

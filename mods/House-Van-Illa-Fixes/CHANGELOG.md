## 1.0.0

First standalone release of House Van Illa fixes for RimWorld 1.6

- Removed the duplicate sword-rack definition while preserving its south-facing entry
- Updated the rimeshroud recipe to use the current hand tailoring bench
- Corrected the offhand parrying dagger texture path
- Applied LunarCygnus's declared wildness of 0.25 through the stat the game uses
- Corrected the dodge radius to the whole number 1, preserving its previous effective value
- Removed an unavailable cooker from four recipes while retaining their other cooking stations
- Replaced the apparel research's missing DankPyon_Tailoring prerequisite with ComplexClothing
- Trimmed whitespace in two precept references
- Replaced the missing Cannibalism meme reference with Cannibal
- Removed the ability's reference to the unavailable PsychicCalmCast sound
- Corrected the original mod's Ideology content gate to check Ideology instead of Royalty

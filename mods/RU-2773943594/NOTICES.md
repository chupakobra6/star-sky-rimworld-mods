# Источники и уведомления

Русский перевод [Geological Landforms](https://steamcommunity.com/sharedfiles/filedetails/?id=2773943594). Автор оригинального мода: m00nl1ght. В README оригинала указаны также Seneral — библиотека Node Editor Framework для редактора, Aranador и Vhalknor — идеи форм рельефа, Seanggag — корейский перевод, dodther — прежний русский перевод. Последний присутствует в установленном оригинале; его авторство сохраняется и совпадающие формулировки не объявляются исключительно нашей работой.

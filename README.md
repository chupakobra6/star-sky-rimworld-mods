Each add-on requires [Harmony](https://steamcommunity.com/sharedfiles/filedetails/?id=2009463077) and [ISEKAI RPG LEVELING](https://steamcommunity.com/sharedfiles/filedetails/?id=3657580708). English and Russian interface text is included. Install only the add-ons you want.

**Previously used Balanced Stats & Quick Quests?** Balanced Stats keeps the original Workshop page. Subscribe to Quick Quests separately for the middle-click shortcut, and update Balanced Stats to **1.2.0 or later** before using both.

## Installation

Subscribe through Steam Workshop, then enable the add-on after its dependencies. For a manual install, copy its folder from `mods/` into RimWorld’s `Mods` directory and enable it. Compiled DLLs are included; game and dependency files are obtained separately.

Each mod’s guide explains settings, load order and upgrading. Its `CHANGELOG.md` records releases. To report a bug, use the relevant Workshop page and include the game/mod versions, steps to reproduce and a log with personal information removed.
